# PPT 风格索引

| 分类 | 子风格 | 适合的任务 |
|---|---|---|

## 从候选到试稿

1. 用户已指定子风格时直接使用相应风格卡。用户只给了大的方向时，先在索引缩小范围，再读涉及的卡片。结合场景、观众、演示距离与内容密度，给出两至三个子风格、各一句区别和对应的参考链接。候选足够让用户区分即可。
2. 用户提供品牌手册、原 PPT、参考图或自定义风格时，提取其配色、文字层级、网格、元素轮廓、图表编码及版式角色，写成一张相同结构的自定义卡。来源文件和限定事项一并记录。素材使用按用户给定的用途或明确许可处理。外部仓库资源默认以链接供预览，交付中的参考内容需要符合对应素材的授权。
3. 以选定子风格的「共同规范」写风格记录。填写具体字体或可用的中文替代、各层级字号、页边距、间距、数字列对齐、页眉页脚和图表编码。文案多或比例特殊时，调整栅格和字号到实际可读。
4. 每页从同一风格卡选一个页型。开场用封面，论证、章节、方法、流程和结论用正文，数据集中的页面用数据页。研究报告风的正文和数据页都先确定架构图、流程图或机制图，再把统计图排入对应节点。章节和结论页可降低密度。把卡片对应段落与该页的真实文案和布局一起送给 ImageGen。
5. 先生成一张代表页。用户认可后，将该图、风格版本和共用规范作为整套约束。换色、换字体气质或换主题导致风格身份改变时生成新代表页。确认后的示意或数据差异按逐页提示词流程修订。

## 项目风格记录

每次实际制作保存一份记录到成品工作目录，文件名可用 `style-lock.md`。用于复查批量原型是否沿用同一视觉规则，也用于重生成单页。

| 字段 | 记录内容 |
|---|---|
| 选择 | 分类、子风格 ID 或自定义 ID、用户确认的页数和比例 |
| 参考 | 风格卡链接、本次使用的外部参考链接或用户素材路径 |
| 版式 | 背景、正文、强调、边线与图表系列色，字体及字级，网格与间距，容器和图片比例 |
| 页型 | 封面、正文、数据页模板的文本，页眉、页脚和图例所在区域 |
| 试稿 | 页码、ImageGen 图片路径、版本及确认状态 |
